# Raspberry Pi 4 — Hub central

Script Python POO para vision, decision y persistencia.

- `PetClassifier`: identificacion visual de mascotas.
- `MQTTManager`: comunicacion con ESP32-S3 y Node-RED.
- `FeedScheduler`: horarios y raciones por mascota.
- `DatabaseLogger`: registro de consumo en SQLite.

La implementacion se hara despues de validar el diseno.

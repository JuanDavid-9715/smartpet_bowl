Como implementarlo en tu Raspberry.

El servicio corre en la Raspberry, no la landing. Son cinco pasos y no necesitas abrir puertos.

1. Prepara el equipo

Raspberry Pi 4 con Raspberry Pi OS de 64 bits. Instala Python 3 y git.

2. Trae el codigo

git clone https://github.com/JuanDavid-9715/smartpet_bowl
cd smartpet_bowl/software/raspberry-pi

3. Dependencias y modelo

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
python3 download_model.py

4. Configura

Copia .env.example a .env y ajusta el host del broker, el codigo del comedero y la URL del stream.

5. Arranca

.venv/bin/python main.py --check
.venv/bin/python main.py

El modelo se descarga una vez y no vuelve a salir a internet. No se entrena nada y no se llama a ninguna API.

Las fotos de referencia de cada mascota se suben desde la app, en la ficha de la mascota.

Empezar en la nube toma dos minutos.
